## 🎓 プロジェクト・研究活動

### 卒業研究：用途地域推定AIシステム
- **目的**: 衛星画像から用途地域を自動推定
- **アプローチ**: YOLOv8/v11によるインスタンスセグメンテーションとU-Netによるセマンティックセグメンテーションを組み合わせたマルチモデルアーキテクチャ
- **使用技術**: PyTorch Lightning、OpenCV、Rasterio（GeoTIFF処理）
- **特徴**: ピクセル/タイル/ポリゴン単位でのマルチスケール分析を行うカスタム評価パイプライン
